- **개발 3명 동시**(§10-2 "3~4명까지"). **ML 학습이 있는 개발3 회전은 단독** — 이번에도 학습은 빼고 별도 회전.
- 읽을 파일 **3개 제한**(§10-9). 각자 `outputs/qa{1,2}-*.md` 의 **자기 결함 항목만** 읽게 한다.

## 2. 아키텍트가 **먼저** 할 일 (개발자 기동 전)

CSRF 는 27개 POST 에 걸쳐 있어 셋이 제각각 하면 어긋난다. 패턴을 박고 시작한다.

1. `templating.render()` 가 **모든 컨텍스트에 `csrf_token` 을 주입**한다 (`csrf.issue(request)`).
2. `templates/_macros.html` 에 폼 토큰 매크로 하나:
   `{% macro csrf_field() %}<input type="hidden" name="_csrf" value="{{ csrf_token }}">{% endmacro %}`
3. `contracts/interfaces.md` §5 에 **핸들러 첫 줄 규약** 공표: `csrf.require(request, form.get("_csrf"))`.
4. **`CSRF_ENFORCE` 는 셋이 다 연결한 뒤에 1 로 올린다.** 먼저 켜면 쓰기 27개가 전부 403 이다(D-60·D-73).
   올리기 전까지 화면 상단 `CSRF 미적용 (D-60)` 배지를 유지한다 — 조용히 꺼두지 않는다.
