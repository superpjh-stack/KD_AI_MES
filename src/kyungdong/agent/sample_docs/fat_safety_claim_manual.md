# FAT·시운전·클레임 매뉴얼 (예시)

FAT 전 최신 승인 도면 Revision, 계측기 교정, 안전가드, 비상정지, LOTO, 위험성평가를 확인한다. 고온·고압·진공·회전체 시험은 승인된 시험절차와 책임자 입회 아래 수행한다.

불합격은 시험항목, 측정값, 단위, 한계값, 설비·계측기, 원인, 조치, 재시험 결과로 기록한다. 출하 허용은 AI가 자동 결정하지 않으며 품질·기술 책임자가 증빙을 검토해 승인한다. 설치 후 클레임은 프로젝트, 자재 LOT, 도면 Revision, 제작 공정, FAT 기록까지 역추적하고 견적·설계 체크리스트에 재발방지 내용을 반영한다.
