# 견적·조달 의사결정 가이드 (예시)

본 문서는 프로토타입 검색 검증용 가상 기준이다.

## 견적 검토

장비 유형, 산업군, BOM 규모, 설계·제작 예상 공수, 소재 단가, 외주·설치비, 과거 클레임을 함께 검토한다. 추천 원가와 납기는 참고값이며 영업·생산·대표 승인 전에는 고객 견적으로 확정하지 않는다. 위험도가 높으면 유사 프로젝트의 실제원가와 도면 변경 이력을 함께 확인한다.

## 조달 예외

납기 지연 예상이 3일을 넘으면 구매 담당자에게 알린다. 대체 공급사·대체자재는 사양 일치만으로 적용하지 않고 설계, 구매, 품질 승인을 모두 받은 뒤 발주한다. MTC, 발주서, 거래명세서가 자재 LOT에 연결되지 않은 자재는 격리한다.
